## Статус

**Черновик, требует проверки инженером.** Структура полей — моя работа и её
можно принимать. Конкретные значения (диапазоны расходов, тонкость, давление,
расшифровка серий) взяты по смыслу отрасли, а не из ваших данных — их нужно
заменить фактическими. Источник фактических значений уже существует: матрица
подбора в A4-каталоге (CLAUDE.md §7). Задача не «придумать параметры», а
оцифровать существующую матрицу в структуру ниже.

## Главный вывод этапа

Текущие восемь категорий `/shop/katalog-filtrov/` — это не одна классификация,
а пять разных осей в одном плоском списке:

| Категория сейчас | Какая это на самом деле ось |
|---|---|
| ОВГД полнопоточные | серия + схема включения |
| ОВГД неполнопоточные | серия + схема включения |
| с обратной промывкой | способ регенерации |
| дисковые | принцип фильтрации |
| насыпные | принцип фильтрации |
| гидроциклоны | принцип фильтрации |
| для агрессивных сред | рабочая среда + исполнение |
| гидравлические | не определено — см. вопрос 1 |

Из-за этого одна и та же модель обязана лежать в нескольких категориях сразу
или не попасть ни в одну, а подбор по параметрам построить нельзя в принципе.
Разложение по независимым осям (`model-dannyh.md`) — это и есть содержание
Этапа 1.
