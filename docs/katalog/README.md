## Статус

**Ревизия 2.** Первая редакция строилась на одном CLAUDE.md, во второй учтены
пять презентаций компании от 05.09.2026.

Что дали презентации: подтверждённые ТТХ уровня семейства, ответ на вопрос о
«гидравлических», цифры потерь на сброс, продукт «система СОФ», которого не
было ни в CLAUDE.md, ни на сайте. Одна моя гипотеза при этом опровергнута —
см. вопрос 2.

Чего по-прежнему нет: **ТТХ уровня типоразмера.** «3–8000 м³/ч» — это
диапазон семейства, а карточка каталога это конкретная модель. Нужна
машиночитаемая таблица моделей.

Всё, чего я не знаю и не стал угадывать молча, — в `voprosy-inzheneru.md`.

## Главный вывод этапа

Текущие восемь категорий `/shop/katalog-filtrov/` — это не одна классификация,
а пять разных осей в одном плоском списке:

| Категория сейчас | Какая это на самом деле ось |
|---|---|
| ОВГД полнопоточные | серия + схема включения |
| ОВГД неполнопоточные | серия + схема включения |
| с обратной промывкой | способ регенерации |
| дисковые | принцип фильтрации |
| насыпные | принцип фильтрации |
| гидроциклоны | принцип фильтрации |
| для агрессивных сред | рабочая среда + исполнение |
| гидравлические | привод очистки — ось найдена по презентациям, вопрос 1 закрыт |

Из-за этого одна и та же модель обязана лежать в нескольких категориях сразу
или не попасть ни в одну, а подбор по параметрам построить нельзя в принципе.

**Уточнение по ревизии 2.** Презентации показали, что те же смешанные
признаки — это язык, которым компания сама описывает линейку: шесть семейств
воспроизводятся во всех версиях презентации и в печати. Ломать этот язык не
нужно. Решение — два уровня: семейства как основная навигация, ортогональные
оси под ними для подбора и сквозных посадочных. Подробно в `model-dannyh.md`.
