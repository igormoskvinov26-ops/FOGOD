# Модель данных каталога

## 1. Правило: таксономия или поле

Единственный критерий, по которому свойство попадает в таксономию:

> **Таксономия** — ось, которой нужна собственная посадочная страница и
> поисковый трафик.
> **Поле** — параметр, по которому только фильтруют и сравнивают.

«Дисковые фильтры» ищут в поиске — это таксономия. «Расход 40 м³/ч» не ищут
как фразу, но по нему подбирают — это числовое поле. Смешение этих двух
сущностей и породило нынешние восемь категорий.

## 2. Оси классификации

Семь независимых осей. Модель получает по одному-двум значениям на каждой,
и ни одна ось не подменяет другую.

### Ось 1. Серия — `seriya`
Собственные разработки ФОГОД: ОВГД, ОСГД, ОМГД. Плюс несерийные позиции.

> ⚠️ Похоже, что вторая буква кодирует среду (**В**ода / **С**ОЖ / **М**асло).
> Если так, ось «Серия» и ось «Среда» частично дублируют друг друга, и это
> надо развести до наполнения. Вопрос 2.

### Ось 2. Принцип фильтрации — `princip`
Как устроена очистка: гидродинамический самоочищающийся, сетчатый, дисковый,
насыпной (зернистая загрузка), гидроциклонный, картриджный, магнитный.

Сюда уезжают нынешние «дисковые», «насыпные», «гидроциклоны».

### Ось 3. Схема включения — `shema`
Полнопоточная (весь поток через фильтр) или неполнопоточная, она же
байпасная (очищается часть потока в контуре).

### Ось 4. Регенерация — `regeneraciya`
Самоочистка потоком, обратная промывка, ручная разборка, сменный элемент.

Сюда уезжает нынешняя категория «с обратной промывкой».

### Ось 5. Рабочая среда — `sreda`
Вода (техническая, оборотная, речная), масло, СОЖ, агрессивные среды,
топливо. Множественное значение: одна модель работает на нескольких средах.

### Ось 6. Исполнение — `ispolnenie`
Коррозионная стойкость и материал: углеродистая сталь, нержавеющая,
с внутренним покрытием или футеровкой.

Нынешнее «для агрессивных сред» — это пересечение оси 5 и оси 6, а не
отдельная категория.

### Ось 7. Отрасль — `otrasl`
Машиностроение, энергетика, металлургия и далее. Ось нужна не для подбора,
а для посадочных страниц под отраслевой запрос.

## 3. Тип записи «Фильтр»

Одна запись = одна модель или типоразмер. Слаг — по обозначению модели.

### 3.1. Идентификация
| Поле | Тип | Прим. |
|---|---|---|
| `model` | строка | обозначение по КД, например ОВГД‑100 |
| `nazvanie` | строка | человекочитаемое название |
| `patent` | строка | номер патента, если есть |
| `status` | выбор | серийная / под заказ / снята с производства |

Обозначение модели набирается моноширинным шрифтом и проходит через линтер
кириллицы и латиницы (позиция 5.5) — `8H5.1` и `8Н5.1` внешне неразличимы.

### 3.2. Гидравлика — основа подбора
| Поле | Ед. | Прим. |
|---|---|---|
| `rashod_min`, `rashod_max` | м³/ч | рабочий диапазон производительности |
| `rashod_nom` | м³/ч | номинал, по нему считается запас при ранжировании |
| `tonkost_min`, `tonkost_max` | мкм | диапазон тонкости фильтрации |
| `tonkost_tip` | выбор | номинальная / абсолютная — вопрос 3 |
| `davlenie_rab` | МПа | рабочее давление |
| `davlenie_max` | МПа | предельное |
| `perepad_chistyj` | МПа | потеря давления на чистом фильтре |
| `dn` | мм | условный проход |
| `temp_min`, `temp_max` | °C | диапазон температур среды |
| `poteri_na_sbros` | % от расхода | расход на самоочистку — вопрос 4 |

`poteri_na_sbros` — параметр, который заказчик считает в экономике объекта.
Если у самоочищающихся серий он ниже, чем у промывных аналогов, это прямой
коммерческий аргумент, и он должен быть в карточке, а не в PDF.

### 3.3. Конструкция
| Поле | Ед. |
|---|---|
| `prisoedinenie` | выбор: фланцевое / резьбовое / муфтовое / под приварку |
| `material_korpusa` | строка |
| `material_elementa` | строка |
| `ploschad_filtracii` | м² |
| `polozhenie` | выбор: вертикальное / горизонтальное |
| `massa` | кг |
| `gabarity` | Д×Ш×В, мм |

### 3.4. Документы и медиа
- `dokumenty` — повторитель: файл + тип (паспорт, опросный лист, габаритный
  чертёж, сертификат, 3D-модель)
- `render` — основной рендер, вырезанный по цветовой дистанции (CLAUDE.md §2)
- `galereya`, `video`, `chertezh`

Опросный лист на карточке — это второй по значимости конверсионный элемент
после кнопки КП: инженер скачивает его и возвращается с готовым ТЗ.

### 3.5. Связи
- `analogi` — какое оборудование замещает

  Отдельно проговорю: в промышленном B2B в РФ запрос «аналог <импортный
  бренд>» — это живой поисковый трафик и готовый горячий лид. Поле стоит
  завести сразу, даже если наполнять начнёте позже.
- `keysy` — объекты, где установлено
- `soputstvuyuschie` — сопутствующие позиции

## 4. Структура URL

Коллизия «термин таксономии против слага товара» решается разделением
пространств имён:

```
/katalog/                        фасетный каталог, все модели
/katalog/seriya/ovgd/            ось 1
/katalog/tip/diskovye/           ось 2
/katalog/shema/polnopotochnye/   ось 3
/katalog/sreda/sozh/             ось 5
/katalog/otrasl/metallurgiya/    ось 7
/filtr/ovgd-100/                 карточка модели
/podbor/                         матрица подбора
```

### Комбинации осей и ловушка фасетного SEO
Страницы вида `/katalog/seriya/ovgd/shema/polnopotochnye/` ищут, и их стоит
отдавать статически. Но все возможные пересечения семи осей — это тысячи
страниц-дублей, за которые сайт получит санкции.

**Правило:** заранее генерируются только те комбинации, где есть и модели
(не меньше трёх), и подтверждённый спрос. Все остальные фильтрации живут в
query-параметрах и закрыты `noindex`, canonical ведёт на базовую ось.

### Слаги
`gidrocziklony` — артефакт плагина транслитерации, который передаёт «цы» как
`czy`. Правильный слаг `gidrociklony`. Такие же проверить по всему каталогу
перед миграцией; карта редиректов — Этап 3, но решения по слагам принимаются
здесь.
