# Документация проекта

| Раздел | Что внутри | Статус |
|---|---|---|
| `etap-0/` | правки на текущем сайте: команды, редиректы, проверка | готово к исполнению, нужны доступы |
| `katalog/` | модель данных каталога и логика подбора | ревизия 2, ждёт ТТХ типоразмеров |
| `kopirajt/` | расхождения в формулировках между материалами | 7 пунктов к решению |

Проектный контекст — `../CLAUDE.md`. Решения по стеку, каталогу, лидам,
языкам, шрифту и доменам — раздел 5 там же.

## Что чем блокируется

- **Этап 0** не зависит ни от чего, кроме доступа к сайту. Делается первым.
- **Этап 1** (каталог) готов структурно, наполнение ждёт машиночитаемых ТТХ
  и ответов по ОСГД/ОМГД.
- **Этап 2** (дизайн) ждёт решения по стеку — позиция 5.1, а она упирается в
  наличие WP-разработчика уровня темы.
